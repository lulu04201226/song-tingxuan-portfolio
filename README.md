# Song Tingxuan — Data and Product Analytics Portfolio

A personal portfolio presenting selected work in product analytics, experimentation, customer behavior, and AI-product research.

**[View the live portfolio](https://song-tingxuan-portfolio.vercel.app)**

## Featured work

- **E-Commerce Funnel Analysis** — conversion diagnostics, cohort comparison, channel standardization, and experiment prioritization.
- **Ride-Hailing Coupon A/B Test** — paired experimental inference, robustness analysis, power, MDE, and subsidy economics.
- **AI Chatbot Preference Analysis** — user-needs classification, response-feature analysis, model comparison, and routing recommendations.

## Focus areas

`Product Analytics` · `Experimentation` · `Growth Analytics` · `Data Visualization` · `AI Product Strategy`

## Technology

Built with TypeScript and deployed on Vercel.

## Local development

```bash
npm install
npm run dev
```

## Purpose

The portfolio is designed to make analytical reasoning visible: each project connects a business question to a reproducible method, quantified evidence, decision implications, and clearly stated limitations.
